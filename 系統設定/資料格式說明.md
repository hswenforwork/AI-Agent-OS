# AI 代理資料格式說明

平台從 `AI代理資料.json` 讀取代理資訊。

| 欄位 | 用途 | 範例 |
|---|---|---|
| 名稱 | 代理顯示名稱 | 研究代理 |
| 圖示 | 卡片圖示 | 🔎 |
| 角色 | 主要職責 | 資料研究與資訊整理專家 |
| 狀態 | 目前狀態 | 工作中 |
| 任務 | 正在處理的工作 | 整理 AI 平台參考資料 |
| 完成進度 | 0 到 100 的數字 | 60 |
| 最後更新 | 最近更新日期及時間 | 2026-09-14 11:20 |
| 位置 | 畫布的預設座標 | `{ "x": 70, "y": 230 }` |

`連線` 用來表示代理之間的協作關係，每一條連線都由兩個代理名稱組成。名稱必須與 `AI代理` 清單完全相同。
