# 已知問題與規則（共用錯誤記憶）

## 這份文件的用途

這是全部 AI 代理共用的一份「教訓清單」。目的是解決使用者最頭痛的問題：**工具改壞了不知道、同樣的錯誤重複發生**（2026-09-14 grill-me 訪談，`context/about-me.md` top_pain）。

每一位代理，不管用哪個模型（Gemini／ChatGPT／Claude），開始任務前都會讀到這份文件。規則很簡單：

1. **檢查代理**確認一個真實問題（不是誤判）之後，必須依下面的格式，把它新增一條到「已確認問題」清單。
2. 任何代理（包含檢查代理自己）在動手前，**先看這份清單有沒有相關項目**，避免重複犯同一個錯，或用同一個錯誤的做法。
3. 條目只增加、不刪除，除非使用者確認這個問題已經徹底解決且不會再發生——這時候把它移到「已解決」區塊並保留原始記錄，不要直接刪掉。
4. 使用繁體中文、寫清楚「發生在哪裡」「錯在哪裡」「以後要怎麼避免」，不要只寫「有 bug」。

## 記錄格式

```
### 【日期】簡短標題
- 發生階段／代理：
- 問題描述：
- 根本原因：
- 以後要怎麼避免：
- 確認者：
```
