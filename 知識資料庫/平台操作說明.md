# 平台操作說明

## 一、打開管理平台

使用瀏覽器開啟 GitHub Pages 網址。左側有四個功能：團隊畫布、文件資料庫、任務進度、工作紀錄。

## 二、查看 AI 代理

在「團隊畫布」中，每張卡片代表一位 AI 代理。卡片會顯示代理名稱、角色、狀態、目前任務及完成進度。代理卡片可以拖曳，位置會保存在目前使用的瀏覽器。

## 三、更新代理資料

1. 在 GitHub 儲存庫開啟 `系統設定` 資料夾。
2. 開啟 `AI代理資料.json`。
3. 按右上角的鉛筆圖示。
4. 修改文字、完成進度或最後更新時間。
5. 按「Commit changes」儲存。

完成進度請輸入 0 到 100 的數字，不需要加百分比符號。每個逗號與雙引號都必須保留。

## 四、新增代理

複製一整段現有代理資料，貼在上一位代理資料後方，再修改名稱、角色與任務。兩段代理資料中間必須有逗號。

## 五、閱讀文件

進入「文件資料庫」，按文件卡片下方的「開啟文件」，即可在 GitHub 閱讀對應的繁體中文 Markdown 文件。

## 六、常見問題

### 顯示「尚無資訊」

代表該代理缺少對應欄位。請確認欄位名稱是否正確：`名稱`、`角色`、`狀態`、`任務`、`完成進度`、`最後更新`。

### 網頁沒有立即更新

GitHub Pages 發布通常需要一些時間。稍候數分鐘後重新整理瀏覽器。

### 卡片位置想恢復預設值

清除這個網站的瀏覽器儲存資料，再重新整理頁面。
