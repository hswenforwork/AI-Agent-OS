# AI 代理團隊

這裡保存六位 AI 代理的正式職務設定。網站會從 `系統設定/AI代理資料.json` 讀取設定，並在呼叫 Gemini 時真正套用。

## 團隊成員

| 代理 | 主要責任 | 預設模型 |
|---|---|---|
| 團隊主管 | 理解目標、分工、整合決策 | Gemini 3.8 Flash |
| 研究代理 | 搜尋、查證、整理證據 | Gemini 3.8 Flash |
| 規劃代理 | 拆解工作、安排順序、定義驗收 | Gemini 3.8 Flash |
| 開發代理 | 技術設計、程式實作、API 整合 | Gemini 3.8 Flash |
| 檢查代理 | 測試、安全、品質與需求驗收 | Gemini 3.8 Flash |
| 文件代理 | 操作教學、成果與知識整理 | Gemini 3.5 Flash-Lite |

## 可觀察的代理自主行為

- 固定身分、人格、核心目標與工作原則。
- 每位代理擁有不同專業、技能、工具與知識文件。
- 單獨對話時保留各自的本分頁短期工作記憶。
- 全隊協作時依序執行並把產出交接給下一位代理。
- 畫布會顯示工作中、已完成、目前任務與完成進度。

這些是軟體實作的代理行為，不代表模型具有人類意識或感受。
