# 個人多元 AI 代理團隊管理平台

這是一套以 GitHub 為資料庫、GitHub Pages 為畫面的免費雲端 MVP。公用電腦只要有瀏覽器即可使用，不需要安裝或下載任何軟體。**2026-09-14 起升級為多元 AI 模型團隊**：同一個平台可以指派任務給 Google Gemini、OpenAI ChatGPT、Anthropic Claude 三家的模型，不只是單一供應商。

## MVP 已有功能

- 視覺化 AI 代理協作畫布，代理卡片拖曳與瀏覽器位置記憶
- 多供應商工作台：Gemini／OpenAI／Claude，每次任務可手動選擇要用哪個模型
- 啟動全隊：依序呼叫六位代理協作，**每完成一個階段就暫停，等你核准才繼續下一階段**（分階段確認制）
- 品保檢查可依任務手動略過，節省成本
- 即時費用估算與每月預算追蹤（僅供參考，非供應商官方帳單）
- 共用錯誤記憶：品保確認過的真實問題會寫進 `知識資料庫/已知問題與規則.md`，所有代理、不管哪個模型接手都會先讀過，避免重複犯錯
- 工作狀態、目前任務、完成進度與最後更新
- 團隊摘要數字與即時搜尋
- 知識文件快速入口
- 任務進度清單
- 最近工作紀錄時間軸
- 手機、平板與電腦自動排版
- JSON 讀取失敗時的備援資料，避免空白畫面

## 使用方式

1. 開啟本專案的 GitHub Pages 網址。
2. 使用左側選單切換「團隊畫布、AI 工作台、文件資料庫、任務進度、工作紀錄」。
3. 在「AI 工作台」選擇代理與模型（供應商＋模型），貼上對應的 API 金鑰。金鑰只暫存在目前分頁，不會被保存。
4. 要更新代理資料時，在 GitHub 開啟 `系統設定/AI代理資料.json`，按鉛筆圖示編輯後提交。
5. GitHub Pages 通常會在提交後數分鐘內自動更新。

詳細步驟請閱讀：[平台操作說明](知識資料庫/平台操作說明.md)、[多模型 API 串接說明](知識資料庫/多模型API串接說明.md)。

## 資料夾

- `AI代理`：每位 AI 代理的職責與工作方式。
- `知識資料庫`：團隊規則、參考資料、操作說明與共用錯誤記憶。
- `工作紀錄`：任務、問題與完成報告。
- `系統設定`：平台使用的代理與 AI 服務 JSON 資料。
- `雲端函式`：未來若要把金鑰搬到伺服器端（例如做真正的背景自動化），保留的 Cloudflare Worker 起點；目前網站不會呼叫它。
- `index.html`：GitHub Pages 顯示的完整平台。

## 免費雲端架構

瀏覽器 → GitHub Pages → `index.html` → `系統設定/*.json` → Markdown 文件；AI 呼叫則是瀏覽器直接連到你貼上金鑰的供應商。

平台本身（畫布、任務板、文件庫）維持零成本、免安裝、免伺服器；AI 對話與團隊協作會依你使用的供應商與模型計費，費用不會經過本平台或 GitHub，直接由你與供應商之間結算，平台只做粗略估算提醒。這是 2026-09-14 grill-me 訪談確認的方向：接受依用量計費的 API，並用分階段確認、可略過的品保、費用預估這三個機制控制風險，詳見 [開發計畫與路線圖](知識資料庫/開發計畫與路線圖.md)。
