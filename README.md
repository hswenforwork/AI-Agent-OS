# 個人 AI Agent 團隊管理平台

這是一套以 GitHub 為資料庫、GitHub Pages 為畫面的免費雲端 MVP。公用電腦只要有瀏覽器即可使用，不需要安裝或下載任何軟體。

## MVP 已有功能

- 視覺化 AI 代理協作畫布
- 代理卡片拖曳與瀏覽器位置記憶
- 工作狀態、目前任務、完成進度與最後更新
- 團隊摘要數字與即時搜尋
- 知識文件快速入口
- 任務進度清單
- 最近工作紀錄時間軸
- 手機、平板與電腦自動排版
- JSON 讀取失敗時的備援資料，避免空白畫面

## 使用方式

1. 開啟本專案的 GitHub Pages 網址。
2. 使用左側選單切換「團隊畫布、文件資料庫、任務進度、工作紀錄」。
3. 要更新代理資料時，在 GitHub 開啟 `系統設定/AI代理資料.json`，按鉛筆圖示編輯後提交。
4. GitHub Pages 通常會在提交後數分鐘內自動更新。

詳細步驟請閱讀：[平台操作說明](知識資料庫/平台操作說明.md)。

## 資料夾

- `AI代理`：每位 AI 代理的職責與工作方式。
- `知識資料庫`：團隊規則、參考資料與操作說明。
- `工作紀錄`：任務、問題與完成報告。
- `系統設定`：平台使用的代理 JSON 資料。
- `index.html`：GitHub Pages 顯示的完整平台。

## 免費雲端架構

瀏覽器 → GitHub Pages → `index.html` → `系統設定/AI代理資料.json` → Markdown 文件

目前版本刻意不使用付費伺服器、資料庫、套件或 API 金鑰。GitHub 只負責保存資料與發布靜態網頁。
