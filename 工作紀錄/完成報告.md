## 2026-09-14：AI 代理團隊行為核心升級

### 完成內容

- 建立六位代理的模型、人格、核心目標、專業、技能、工具與知識範圍。
- 單一代理會依自己的完整設定呼叫 Gemini，不再共用單一通用提示。
- 各代理在目前分頁擁有獨立短期工作記憶。
- 研究代理可使用 Gemini Google 搜尋工具。
- 代理可讀取各自指定的 GitHub Pages Markdown 知識文件。
- 新增六位代理依序執行與交接的「啟動全隊」流程。
- 畫布會在執行期間更新代理狀態、任務、進度與時間。
- 補齊六份繁體中文代理職務文件與資料格式說明。

### 驗證結果

- JavaScript 語法檢查通過。
- AI 代理 JSON 格式與必要欄位檢查通過。
- 六位代理及六階段團隊流程檢查通過。
- GitHub 提交內容不包含 Gemini API 金鑰。

### 限制

- 代理的人格、目標與記憶是軟體定義的行為，不代表人類意識或感受。
- 全隊協作約呼叫六次 Gemini API，會使用相應額度。
- 工作記憶目前只保留在分頁，重新整理後會清除。

## 2026-09-14：Gemini 免費額度修正

- 原因：Gemini 3.1 Pro 在目前 Google 專案的免費額度上限為 0。
- 團隊主管與開發代理改用 Gemini 3.8 Flash 作為預設模型。
- 文件代理維持 Gemini 3.5 Flash-Lite。
- Pro 發生 429 額度錯誤時，網站會自動嘗試 Flash，再嘗試 Flash-Lite。
- 縮短每位代理載入的知識內容，降低全隊協作的輸入 Token 使用量。
